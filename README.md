# VishwaaFX Quote Desk

Phone-first quotation app for VishwaaFX: project quotes (initial + additional bills, quality options),
on-site supervision bills, payment tracking, note templates, letterhead PDF export and Google Drive sync.

Live app: https://dicksonpjo-sys.github.io/quote-desk/

See `SETUP.md` for how the hosting and Google Drive connection are set up.
